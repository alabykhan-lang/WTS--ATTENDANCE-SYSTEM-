# Corrections and audit

Correction requests record person, date, AM/PM or check-in/check-out scope, current value, requested value, reason, supporting note, requester, reviewer, decision and applied time.

Ordinary staff can request their own correction. Class teachers can request pupil corrections in an assigned class. Only an authorised Attendance reviewer or administrator can approve. The requester cannot independently approve their own request unless the configured super-administrator policy explicitly allows it.

Approval changes the official interpretation and recalculates affected summaries. It never deletes the raw event, the previous interpretation or the request. Register corrections are applied to the session record and marked as `correction` source.
